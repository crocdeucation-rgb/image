2담당자는 이제 자동 배정됩니다

신규 리드가 들어오면 담당자가 자동으로 정해지고, 슬랙으로 알려드립니다.

리드가 등록되면 담당자가 자동으로 배정되고, 리드알림 채널에 🔔 배정 → @담당자 멘션이 옵니다.
· 신규 번호 → 활성 담당자끼리 순번대로 배정
· 중복 번호(같은 번호 재신청) → 이전 담당자에게 자동 승계
멘션이 오면 그 리드는 여러분 것 — 내용 칸에 정해진 단어/형식으로 상담 결과만 적으면 끝. (예: 안 받으면 부재 → 상태가 자동으로 '부재/OFF')
쓰고 나면 시스템이 처리 완료 표시로 내용 끝에 [✓]를 자동으로 붙입니다.

5수정할 땐 [✓] 뒤에 쓰세요

한 번 파싱되면 내용 끝에 [✓] 표시가 자동으로 붙습니다. 이게 '처리 완료' 도장이에요.

📌
같은 리드를 또 바꾸고 싶으면, 반드시 [✓] 뒤에 새 내용을 쓰세요.
예: 내용이 부재 [✓] 상태인데 방문이 잡혔다면 → 뒤에 이어서 방문 7/1 오후 3시 라고 쓰면 다시 인식됩니다.
[✓] 앞을 고치면 "이미 처리된 것"으로 보고 반영이 안 될 수 있어요.
🔁
방문이 연기됐을 땐? 취소하지 말고, [✓] 뒤에 새 방문 날짜·시간만 다시 쓰면 됩니다. (예: 방문 [✓] 뒤에 이어서 방문 7/5 오후 3시)
→ 일정이 새 날짜로 갱신되고 '연기됨'으로 표시됩니다. 방문을 아예 없애는 '방문취소'와는 다르니 주의하세요.

6직접 해야 하는 것 (자동 안 됨)

담당자 배정까지 자동이 됐지만, 방문 취소만은 손으로 처리합니다.

  1. 방문 취소 — 잡혔던 방문이 완전히 취소되면: ① 노션 방문 일정 칸의 날짜를 우클릭 → 삭제 → ② 상태를 '방문취소'로 직접 변경하세요. (이건 자동 안 됨)
    ※ 날짜만 바뀐 '연기'는 취소가 아닙니다 — 위 5번처럼 새 날짜를 다시 쓰세요.

7중복은 자동 처리됩니다

같은 전화번호로 또 신청이 들어오면 시스템이 알아서 '중복'으로 표시하고, 이전 기록을 내용 칸에 붙여줍니다.

전화번호가 같으면 자동으로 '중복' 상태가 되고, 내용 칸에 이전 신청 기록(날짜·담당자·상태)이 함께 표시됩니다. 담당자도 이전에 맡았던 사람에게 그대로 승계돼요. 따로 손댈 필요 없이, 이전에 어떤 상담이었는지 바로 확인만 하면 됩니다.

8우선연락 표시

꼭 빨리 연락해야 하는 리드는 우선 표시를 해두면 우선순위 필터로 모아볼 수 있습니다.

  1. 내용에 우선연락 이라고 쓰면 → 📌 우선 체크박스가 자동으로 켜집니다.
  2. 또는 노션에서 📌 우선 칸의 체크박스를 직접 클릭해도 됩니다.
  3. 표시된 리드는 '우선 순위' 필터로 끼리끼리 모아볼 수 있어요.
‘우선 순위’ 필터로 📌 체크된 리드만 모아본 화면입니다.
