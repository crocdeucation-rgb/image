블로그 에이전트 기획

Claude 에이전트 기반 · 입시정보 블로그 매일 자동 생성 (뉴스 원고 예시 포함)
작성 2026-09-22 · 신상준(CGO) · 쌤이다/아라온 블로그 대상 · 연계 문서: 2부「수행평가 데이터허브 구축 기획」
한 줄 요약
입시 주제 하나만 던지면, Claude 에이전트가 최신 정보를 스스로 수집·작성·카드 생성해 네이버 블로그에 발행합니다. 사람은 검토·승인만. 사진은 자동화 불가 → 정보 카드로 대체.
목차
1. 무엇을 자동화하나 2. 이미지 해결(핵심) 3. 이전 봇과의 차이 4. 자동화 단계 5. 콘텐츠 주제 6. 로드맵 부록. 뉴스 원고 예시 1부

1. 무엇을 자동화하는가

지금은 블로그 한 편을 쓰려면 자료조사 → 글작성 → 이미지제작 → 발행을 사람이 전부 수동으로 합니다. 이 네 단계를 에이전트가 자동 수행하고, 사람은 '검토·승인'만 담당합니다.

1
키워드 입력  입시 주제 하나 (예: '2028 통합사회 중등 준비'). 사람이 주거나 주제 풀에서 자동 선택.
2
자료 수집  웹검색으로 교육부 발표·입시 일정·전형 정보를 실시간 수집.
3
글 작성  아라온 톤 + 학부모 눈높이. 불안 마케팅 배제, 자기주도학습 자연 연결, SEO·출처 명시.
4
이미지 생성  글 핵심을 '정보 카드'(요약표)로 자동 제작 → PNG. 저작권 0, 브랜드 통일.
5
자동 발행  네이버 블로그 글쓰기 API로 제목·본문·이미지·태그 발행.
총 소요: 글 한 편당 사람 개입 5분 이내(검토·승인). 매일 1~3편 발행 가능.

2. 이미지는 어떻게 하는가 — 핵심

글은 완전 자동이지만, 사진은 100% 자동이 불가능합니다. 아무 사진이나 자동으로 가져다 쓰면 저작권 위반·네이버 저품질 위험이 있기 때문입니다.

방법자동화저작권품질 · 비고
정보 카드 (직접 생성)반자동안전★추천. 요약표·일정표를 브랜드 카드로. 입시글엔 사진보다 표가 강함
AI 이미지 생성자동안전입시 정보글엔 어색할 수 있음. 감성글엔 적합
무료 스톡자동안전무난하나 뻔함. 다른 블로그와 겹침
직접 촬영 사진수동안전품질 좋으나 손이 감. 후기·현장글용
결론 — 입시 블로그는 '사진'보다 '정보 카드'가 맞다. 학부모는 예쁜 사진보다 요약표·일정표를 원함. 이 카드는 아라온이 이미 쓰는 방식(HTML→PNG)이라 파이프라인에 바로 붙고, 저작권 0 + 브랜드 통일 + 정보 전달력 최고. → 부록 뉴스 원고의 파란 표가 실제 예시.

3. 이전 봇들과 무엇이 다른가

"클로드로 블로그 자동 발행"은 예전에도 있었지만, 2026년의 에이전트는 근본적으로 다릅니다. 사람이 단계마다 개입하던 '스크립트'에서, 스스로 판단하고 도구를 쓰는 '에이전트'로 진화했습니다.

단순 API 스크립트

  • 발행·이미지 사람이 다
  • 최신 입시정보 반영 불가

4. 자동화 수준 (단계적 도입)

단계방식설명
1단계 (시작)반자동에이전트가 글+카드 완성 → 사람이 검토 후 발행
2단계자동 발행네이버 API 연결 → 초안 바로 발행, 사후 점검
3단계 (완성)완전 자동스케줄러가 매일 자동 발행
주의: 처음부터 3단계로 가지 않음. 1단계로 글 몇 편 쌓아 네이버 검색 노출과 품질을 검증한 뒤 올림. API 발행 글의 노출 여부가 첫 관문.

5. 발행할 콘텐츠 주제

주제소스비고
입시뉴스·전형웹검색 (교육부·입시매체)완전자동 이번 기획의 주력. 남들도 쓰는 소스라 빠른 검증용
수행평가 (학교별)자체 데이터허브 (독점)→ 2부 문서 참조. 뉴스로 못 만드는 아라온만의 차별화
2축 전략: 뉴스형(입시)은 남들도 쓰는 소스라 빠른 검증·가동용. 데이터형(수행평가)은 아라온만의 독점 무기(2부). 뉴스형으로 먼저 돌리고, 데이터형은 병렬 구축.

6. 실행 로드맵

1
다음 주 월요일  쌤이다 사업자 단체 아이디로 네이버 블로그 개설 (사업자등록증 필요 → 월요일 발급 예정)
2
즉시  네이버 개발자센터 앱 등록 → 블로그 글쓰기 API 권한 신청
3
1차 검증  입시뉴스 주제로 글+카드 1편 발행 → 네이버 검색 노출 확인 (관문)
4
노출 정상 시  완전자동 구축 → 데일리 업무 편입 (매일 초안 생성 → 검토·발행)
운영 편입: 단체 아이디가 다음 주 월요일 발급되면, 블로그 자동 발행이 데일리 업무에 추가됩니다.

부록. 뉴스 원고 예시 1부

에이전트가 입시뉴스 기사 1건을 받아 자동 생성한 실제 형태입니다. 본문 중간 파란 표가 '정보 카드'(자동 생성). 실제 발행 시 이 형태 그대로 네이버에 올라갑니다.
